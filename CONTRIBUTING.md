# Contributing to SovereignCompute

Thank you for your interest in building a more sovereign and sustainable computing future.

## Ways to Contribute

1. **Code** — Improve the CLI, add workload runners, carbon intensity integrations, protocol implementations.
2. **Protocol Design** — Open issues or PRs discussing the coordination layer, message formats, and security model.
3. **Documentation** — Improve clarity, add examples, translate the manifesto.
4. **Research** — Share papers or findings on efficient local inference, distributed scientific computing, or energy-aware scheduling.
5. **Community** — Help organize discussions, write blog posts, or connect with research groups and NGOs.

## Getting Started

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/amazing-idea`).
3. Make your changes.
4. Commit with clear messages.
5. Open a Pull Request against `main`.

## Code Style

- Python: Follow PEP 8. Use type hints where practical.
- Keep the prototype lightweight (minimal dependencies).
- Prefer clarity over cleverness.

## Code of Conduct

Be respectful, constructive, and inclusive. We are building something for everyone.

## Questions?

Open an issue with the label `question` or `discussion`.

Together we compute.
